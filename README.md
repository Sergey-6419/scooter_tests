# Scooter Tests

Автоматизированный тест для проверки получения данных о заказе по его трек-номеру.

## Сценарий теста

1. Создаётся новый заказ.
2. Из ответа сохраняется трек-номер.
3. Выполняется запрос на получение заказа по трек-номеру.
4. Проверяется, что сервер возвращает код `200`.

## Структура проекта

* `configuration.py` — URL сервера и пути API.
* `data.py` — данные для создания заказа.
* `sender_stand_request.py` — функции для отправки API-запросов.
* `get_order_by_track_test.py` — автотест.
* `main.py` — запуск теста.
* `.gitignore` — файлы и папки, исключённые из Git.

## Запуск

или:
